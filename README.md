# KEYFLOW
### Type faster. Find your flow.

## Project Overview
KEYFLOW is an interactive typing speed test web application designed to help users improve their typing speed, accuracy and consistency through a clean, engaging and distraction-free interface.

## Key Features
- Multiple test durations: 15, 30 and 60 seconds.
- Real-time typing speed and accuracy tracking.
- Multiple themed typing passages.
- Instant performance analysis with detailed statistics.
- Velocity timeline graph to visualise typing performance.
- Personal best records and test history.
- Light and dark modes.
- Toggleable typing sound effects.
- Shareable test results.
- Local storage for saving personal statistics.

## Technologies Used
- HTML5 – Application structure
- CSS3 – Styling and user interface
- JavaScript – Functionality and interactivity
- Google Antigravity – AI-assisted development
- Netlify – Web hosting

## How to Use
1. Select your preferred test duration.
2. Choose a typing passage theme.
3. Start typing to automatically activate the timer.
4. Complete the test to view your performance report.
5. Track your progress through the personal statistics dashboard.

## Design Philosophy
KEYFLOW combines a minimalist interface, warm ivory backgrounds, deep navy typography and soft lavender accents to create a focused and visually appealing typing experience.
